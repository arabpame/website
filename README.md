# EARTHLINK Philippines

A digital environmental action platform. See the problem. Connect the people. Create the solution.

A resident reports an environmental problem, it becomes a numbered case, the community
verifies it, it is referred to the office that can act on it, volunteers act, and the public
watches the status until it is resolved. This repository is the live site: every screen of the
platform, a working report intake, and a case register built from documented 2026 incidents.

---

## Stack

| Layer | Choice |
|---|---|
| Framework | Next.js 16.3 (App Router) |
| Runtime | React 19.3 |
| Language | TypeScript, strict, with `noUncheckedIndexedAccess` |
| Styling | Tailwind CSS 3.4 |
| Fonts | Bricolage Grotesque, Public Sans, JetBrains Mono, via `next/font` |
| Data | Documented cases and missions as code in `data/*.ts`, compiled from `data/source/*.json`. Filed reports in Supabase. See `STACK_DECISION.md` |
| Intake | Server Actions. Reports to Supabase (table plus private storage bucket), email through Resend. Both by plain `fetch`, no SDKs |
| Map | Hand-built SVG from PSA boundary data. No tile provider |
| Hosting | Vercel |

Runtime dependencies: `next`, `react`, `react-dom`. That is the whole list.

## Quick start

```bash
node scripts/doctor.mjs   # checks the machine. Runs before npm install
npm install
npm run dev               # http://localhost:3033
```

The site runs with no environment variables and no network. There is nothing to configure.

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Development server on port 3033 (the project folder number) |
| `npm run build` | Production build |
| `npm run verify` | **The definition of done.** Typecheck, contrast, QA, grammar, security, build |
| `npm run doctor` | Checks the machine, not the code. Zero dependencies, runs before install |
| `npm run clean` | Deletes every build cache. Always safe. Run this first when a build fails strangely |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint |
| `npm run contrast` | Computes all 53 colour pairs, writes `docs/CONTRAST.md`, fails on any below target |
| `npm run qa` | Links, metadata, headings, alt text, asset budgets, project rules |
| `npm run grammar` | Em dashes, spelling, repeated words. Prose only |
| `npm run security` | Secrets, fail-open auth, `NEXT_PUBLIC_` leaks, headers |
| `npm run map:build` | Rebuilds `data/ph-map.json` from PSA boundary data. Needs network. Output is committed |
| `npm run assets:build` | Regenerates the favicon, touch icon and OG image |

## Environment variables

The site builds and runs with none. Live report intake needs four, documented in
`.env.example` and set up step by step in `supabase/README.md`: the Supabase URL and service
role key, the Resend key and the address reports go to. Without them a laptop stores reports in
`.cache/` so the flow can be developed offline, and Vercel says reporting is unavailable.

The source of truth for every production value is the provider dashboard, never a file on a
laptop. This folder is inside OneDrive, so a gitignored `.env.local` still syncs to the cloud.

## Deployment

Push to `main`, Vercel builds. `vercel.json` gates the build behind QA, grammar and security,
and sets the house security headers.

Set `NEXT_PUBLIC_SITE_URL` in Vercel before the first deploy, or canonicals and the sitemap
will point at the placeholder domain.

## Project standards

`PROJECT_RULES.md` is the law and is copied in unchanged from the studio playbook. `npm run
verify` is the Definition of Done. `DESIGN_DIRECTION.md` records why this site looks the way
it does, and `handoff.md` is the shared memory for whoever picks this up next.

## Not built yet (by design)

Do not add these without reading `handoff.md` first.

- **No accounts, no login, no admin console.** Filed reports are read and updated in the
  Supabase Table Editor until a verification screen exists.
- **No reporter notifications.** A reporter's contact is stored and emailed to the founder, and
  nothing is sent to the reporter yet.
- **No tile-provider map.** A licensed provider can come later, with clustering at national
  scale. See `STACK_DECISION.md`.
- **No lesson content.** Structure only. Written with teachers.
- **No analytics, no cookies, no tracking.** Nothing is set.
- **No testimonials.** The platform has no users to quote, and inventing them for a civic
  platform would be dishonest.
- **English only.** A real limitation, recorded on the accessibility page.

## A note on the data

Every case on the site is either a report filed through the Report page or a documented 2026
incident taken from published news reporting or an official release, with its sources shown on
the case page. The research record is `data/source/`; `npm run data:build` compiles it. Nothing
is invented, and every dashboard number states what it counts. Until 16 September 2026 the site
carried invented sample data behind a persistent notice; that data and the notice are gone.
