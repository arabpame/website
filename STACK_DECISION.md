# Stack decision

Why this project is built the way it is. Written per `WEBSITE_PLAYBOOK.md` section 1.2, which
requires this file whenever the stack is not the unexamined default.

## The three questions

**Does it need a server?** Eventually, badly. EARTHLINK is authentication, file upload, a
moderation queue, agency accounts, transactional email and a permanent case record. Phase 1
does not, because Phase 1 is the design.

**Will content change without a developer?** Yes, in Phase 2. Case records are created by the
public and edited by a moderation team. That is a database, not a data file.

**How many pages, and do they share layout?** Twenty routes, 84 pages once dynamic routes are
generated, all sharing a header, footer and page-header band.

## The decision

**Next.js 16 App Router, TypeScript strict, Tailwind 3.4, data as code.**

Static HTML would have been faster to build and would have been the right answer for a
brochure site. It is the wrong answer here for one reason: **this codebase is meant to become
the real platform.** Phase 2 adds Supabase, Server Actions, auth and uploads. Building Phase 1
in static HTML would mean throwing it away and rebuilding, which is exactly what the phased
valuation exists to avoid.

So the architecture is the Phase 2 architecture, with the database swapped for
`data/*.ts` behind `lib/store.ts`. When Phase 2 arrives, one file changes.

## Deviations from the house default, with reasons

### Tailwind 3.4, not 4

The studio's brand-token convention lives in `tailwind.config.ts`, and `PROJECT_RULES.md`
requires the brand to live in config with no hardcoded hex in components. Tailwind 4 moves
tokens into CSS `@theme` and drops the JS config, which changes the shape of that convention.
Taking v4 on a client build, for no benefit this project needs, would have been a change made
for its own sake.

### No map tile provider

The concept asks for an interactive map of the Philippines, and the obvious answer is Mapbox
or MapLibre with a tile provider. This build uses a hand-generated SVG instead, from Philippine
Statistics Authority PSGC administrative boundaries.

| | Tile provider | Committed SVG |
|---|---|---|
| API key | Required, and leakable | None |
| Cost | Free to 50,000 loads, then metered | None |
| Content Security Policy | Needs script, style, image and fetch exemptions | None |
| Works offline | No | Yes |
| Renders on the server | No | Yes, so pins are in the HTML for crawlers |
| Street-level detail | Yes | No |
| Clustering at national scale | Yes | Not needed at 37 cases |

The only column a tile provider wins is detail and clustering, and neither matters for a
design build with 37 cases. **Mapbox belongs in Phase 2**, when there is real reporting volume,
real clustering, and a reason to pay for tiles.

The geometry is generated by `scripts/build-map.mjs` and the output is **committed**, so
`npm run build` never touches the network. `scripts/verify-map.mjs` and
`scripts/verify-cases.mjs` confirm the projection is correct by checking that 19 real cities
and all 37 sample cases land inside the regions they claim.

### No database, and no pretending otherwise

`lib/store.ts` is a real data access layer with async functions over `data/*.ts`. The forms
validate properly and then tell the user plainly that nothing was submitted.

The alternative, a form that appears to work and silently discards a real environmental
report, would be worse than having no form at all. Someone will try this build with a genuine
concern.

### Three fonts, not two

The playbook allows a third face only with a reason. The reason: EARTH case numbers,
coordinates, timestamps and counters are tabular data, and setting them in a proportional face
is what makes civic platforms read as brochures. `npm run qa` fails the build if the mono face
is used for prose.

### No state library, no animation library, no UI library

Three runtime dependencies: `next`, `react`, `react-dom`. Every animation is a Tailwind
keyframe. Every primitive is hand-written. Nothing here needed 40 KB of `framer-motion` for a
fade.
